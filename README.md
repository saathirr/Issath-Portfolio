# Mohamed Issath — Quantity Surveyor & Estimation Engineer Portfolio

A modern, responsive, high-performance portfolio website built with **React**, **Vite**, and **Tailwind CSS**, designed with an architectural CAD blueprint aesthetic and construction/QS interactive tools.

## 👷 About Mohamed Issath
- **Position**: Quantity Surveyor (Civil & MEP) | Estimation Engineer
- **Location**: Jeddah, Saudi Arabia
- **Experience**: 6+ Years (Qatar & Sri Lanka)
- **Flagship Project**: ABK Tower, Lusail Boulevard, Qatar (QAR 218 Million)
- **Academic Qualifications**: BSc (Hons) Quantity Surveying & Construction (R) - De Montfort University, UK

---

## 🚀 Key Features

1. **CAD Blueprint & Construction Theme**:
   - Technical crosshair coordinate tracking
   - Animated laser sweep scanner
   - Engineering drawing stamps (IFT, IFC, Shop Drawings)
   - High-vis safety gold and blueprint deep navy color palette

2. **Core Sections**:
   - **01. Home & Hero**: Impactful headline, technical dimension callouts, and key metrics.
   - **02. About Me**: Detailed background, QS pillars, and 5-stage commercial workflow.
   - **03. Professional Experience**: Interactive timeline across Qatar (Al Khaleej Modern Lights) and Sri Lanka (Atham Bawa & Advent Project).
   - **04. Featured Projects**: ABK Tower (QAR 218M), Residential Housing (LKR 4.97M), 16-Storey Condominium (LKR 9.97M) with full BOQ inspector modal.
   - **05. Interactive Blueprint & Take-Off Inspector**: Switch between Architectural, Structural Rebar, and MEP layers with element BOQ audits.
   - **06. Skills & Academic Knowledge**: 12 core professional skills, 8 academic domains, and UK degree credentials.
   - **07. Software & Languages**: Proficiency meters for AutoCAD, PlanSwift, CostX, Revit, SketchUp, and MS Office, plus English & Arabic fluency.
   - **08. Live Take-Off & Cost Estimator**: Interactive calculator simulating Civil, MEP, P&G, and Contingency allocations with concrete/rebar take-off estimates.
   - **09. Printable & Digital CV Modal**: One-click printable PDF view and text copy.
   - **10. Contact & Engagement**: WhatsApp direct chat, phone dialer, email, and inquiry form.

## 💻 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/saathirr/Issath-Portfolio.git

# Navigate into project directory
cd Issath-Portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
